# Маркет MotionLab

Публичный каталог пресетов и наборов настроек. MotionLab читает каталог без сервера и ключей. Установщики приложения остаются в Releases, а файлы маркета — только в этой папке.

## Поделиться работой

1. В MotionLab: «Маркет» → «Профиль автора», сохранить ник и имя GitHub.
2. «Поделиться проектом»: выбрать JSON, PNG, ZIP с JSON/PNG или папку; добавить PNG-превью, описание, категорию, теги, лицензию. Прочитать [правила](rules.md) и подтвердить права.
3. «Подготовить заявку для GitHub»: JSON сохранится локально в `%AppData%\MotionLab\Market\outbox`. Автоматической отправки нет.
4. Создать fork этого репозитория. В своей копии загрузить только подготовленный JSON в `marketplace/submissions`, сохранив UUID-имя файла.
5. Открыть PR в `HeavyFinat/MotionLab-Releases:main`. Дождаться Actions и одобрения владельца. После принятия и пересборки карточка появится в каталоге.

Подтверждённый автор — аккаунт, создавший PR. Ник из заявки не доказывает владение аккаунтом. Заявка добавляет ровно один новый JSON; пользователь не меняет scripts, workflows и чужие файлы.

**Файлы публичного fork/PR доступны ещё до модерации.** Удаление карточки не стирает историю GitHub и скачанные копии. Не загружайте секреты, личные данные и закрытые проекты.

## Владельцу

- Дождаться зелёной проверки «Маркет — проверить заявку». Просмотреть только данные, проверить права, описание, превью и лицензию. Форматная проверка не заменяет модерацию.
- Принять PR. «Маркет — обновить каталог» сверит данные с одобренным PR и запишет `catalog.json`, `owners.json`, `packages/`, `previews/`. Прямое добавление заявки в main не подтверждает авторство и не публикует работу.
- Скрыть: UUID в `hidden` файла [moderation.json](moderation.json). Удалить: UUID в `deleted`. Вернуть скрытую: убрать из `hidden`. Сгенерированный каталог вручную не редактировать.
- Заблокировать: настоящий login в `banned_authors`; при спаме также блокировка пользователя средствами GitHub.
- Обновить популярность: Actions → «Маркет — обновить каталог» → Run workflow. Это положительные реакции на исходные PR. Точного счётчика скачиваний нет.

Пример модерации; вместо примера UUID вставьте существующий:

```json
{"schema_version":1,"hidden":["e7446d10-9362-4911-9d9e-7ad75b5b3b40"],"deleted":[],"banned_authors":[]}
```

## Удаление и жалобы

«Запросить удаление» открывает Issue с заголовком `[Маркет: удалить] UUID` и UUID в поле «Идентификатор публикации». Отправьте её из аккаунта, создавшего PR. Actions проверит реального автора Issue по `owners.json`; владелец репозитория тоже может удалить карточку. Заявление «я автор» в тексте права не даёт. История GitHub сохраняется.

«Пожаловаться» открывает публичную Issue: UUID, причина, для нарушения прав — ссылка на оригинал и описание своего права. Не указывайте личную почту и закрытые сведения. Владелец рассматривает обращение и скрывает материал через moderation.json.

## Лимиты пилота

Пакет до 10 МиБ, PNG-превью до 512 КиБ, JSON/base64-заявка до 15 МиБ. Только схема JSON MotionLab, PNG и проверенный ZIP с ними. Исполняемые форматы и скрипты запрещены. Проверяются SHA-256, CRC, пути, размеры распаковки, бюджеты JSON/PNG; подробности — [правила](rules.md).

До трёх новых PR автора за день по UTC, до десяти активных работ, до 200 принятых работ и 200 МиБ исходных пакетов/превью всего. Скрытые работы активны; удалённые данные остаются в Git-истории и учитываются в общем лимите. Финальная сборка перепроверяет все заявки. Предварительная PR-проверка по текущему публичному каталогу может потребовать повторного решения квоты после других слияний.

Actions отказывает публикации сверх квоты, но не запрещает открывание спам-PR/Issues. Используйте модерацию и блокировки GitHub. При росте объёма потребуется объектное хранилище; этот репозиторий предназначен для небольшого пилота.

## Обслуживание

Три workflow — `.github/workflows/market-*.yml`. Проверка PR запускает доверенный код основной ветки с правами чтения; содержимое заявки не исполняется. Каталог и удаление используют краткоживущий токен Actions с правами записи в репозиторий. Секретов в MotionLab нет. Автоматическое принятие PR не включать.

GitHub может запросить разрешение первого запуска из fork. Если Actions не может записать каталог, проверить журнал, Settings → Actions и защиту main. Не отключать проверку содержимого. При ошибке старый проверенный каталог сохраняется.

Исходники поддерживаются в `HeavyFinat/MotionLab-Build/app/Market`, ветка `feature/market`. Канонические проверки копируются `sync-github-backend.cjs` и обновляются одновременно с приложением.
