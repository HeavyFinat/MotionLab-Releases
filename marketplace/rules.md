ПРАВИЛА МАРКЕТА MOTIONLAB
Версия 2026-10-27.2

1. Публикуйте только свою работу или материалы, на распространение которых у вас есть права. Не включайте чужие платные пресеты, шрифты, музыку, изображения и персональные данные без разрешения.

2. Запрещены вредоносные файлы, скрытый код, спам, обман, контент 18+, материалы, нарушающие закон или авторские права. Не маскируйте исполняемый файл под картинку или настройки.

3. MVP принимает пресеты и наборы настроек в формате JSON MotionLab, PNG и ZIP с такими файлами. Скрипты, EXE, DLL, BAT, JSX, AEP и вложенные архивы не принимаются. До 10 МиБ на пакет, 128 записей в архиве и 32 МиБ после распаковки; отдельный JSON/PNG — до 2 МиБ. Превью: PNG до 512 КиБ, максимум 2048×2048.

4. Перед отправкой выберите лицензию. CC0 разрешает использование без условий; CC BY требует указания автора; CC BY-NC также запрещает коммерческое использование. Упрощённые пояснения не заменяют условия лицензий:
https://creativecommons.org/publicdomain/zero/1.0/
https://creativecommons.org/licenses/by/4.0/
https://creativecommons.org/licenses/by-nc/4.0/
Выбранная лицензия применяется ко всему пакету. Вы должны иметь право предоставить её на каждый вложенный материал. Удаление публикации не отзывает уже предоставленные права на полученные копии.

5. «Подготовить заявку для GitHub» сохраняет выбранный пакет, превью и описание в JSON на вашем компьютере. Вы сами загружаете файл в GitHub и открываете Pull Request. Отправляя PR, вы подтверждаете права и разрешаете показывать и распространять эти материалы по выбранной лицензии. Публикация добровольная. Другие папки приложения и сведения о компьютере не отправляются.

6. В каталог MotionLab работа попадает после проверки и одобрения владельцем. Администратор может скрыть или убрать карточку. Сами заявки, файлы PR и история публичного репозитория GitHub видны ещё до модерации и могут сохраняться после удаления карточки. Не публикуйте секреты, частные проекты и материалы, которые нельзя сделать общедоступными. Проверки не гарантируют качество и пригодность для вашей задачи.

7. Вход для отправки PR и жалоб выполняется в браузере на GitHub. MotionLab не получает пароль или токен GitHub. Локальный профиль содержит ваш ник и указанное имя GitHub; это не подтверждение входа. Автором опубликованной работы считается GitHub-аккаунт, создавший одобренный PR. Ник, аккаунт и опубликованные сведения видны всем.

8. «Пожаловаться» открывает подготовленную жалобу в GitHub Issues. Для нарушения прав укажите спорную работу, оригинал и свои права. Подтвердите отправку в браузере. Жалоба публична: не указывайте личную почту, пароли и лишние личные сведения. Администрация рассмотрит обращение, может запросить пояснения и скрыть материал. Это внутренний механизм обращения без обещания юридической процедуры или срока ответа.

9. Разрешены до 3 новых Pull Request за день по UTC и до 10 активных работ автора. Проверки Actions ограничивают принимаемые публикации. За спам и обход ограничений автор может быть заблокирован в каталоге или на GitHub. Не используйте повторные жалобы для давления на других авторов.

10. Установка сохраняет только проверенные файлы в %AppData%\MotionLab\Market\installed; подготовленные заявки — в outbox рядом. Применять настройки к своему проекту нужно вручную. Перед использованием проверьте содержимое и лицензию, сохраните копию своей работы. Удаление публикации из каталога не отзывает лицензии и не стирает историю GitHub или ранее полученные копии.
