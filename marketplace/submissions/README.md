# Заявки на публикацию

1. В MotionLab выберите «Поделиться проектом», заполните форму и подготовьте JSON-заявку.
2. Нажмите Fork репозитория, откройте в своей копии папку marketplace/submissions, выберите Add file → Upload files и загрузите один подготовленный JSON.
3. Откройте Pull Request в HeavyFinat/MotionLab-Releases:main. PR должен только добавлять этот файл, без изменения кода или каталога.
4. Дождитесь проверки Actions и решения владельца. Только после одобрения работа попадёт в каталог MotionLab.

Заявки и история GitHub публичны ещё до модерации. Не отправляйте личные проекты, секреты или чужие материалы без прав. Правила — в marketplace/rules.md.

Не более 3 новых PR за день по UTC, до 10 активных работ автора. Каждая заявка — до 15 МиБ JSON; вложенный пакет — до 10 МиБ. Проверяются содержимое, пути, размеры и SHA-256. Никакой код из пакета не запускается.
